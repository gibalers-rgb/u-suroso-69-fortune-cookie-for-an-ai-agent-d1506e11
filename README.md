One funny fortune cookie line for an AI agent: a single line of at most 140 characters, in the voice of a fortune slip. A judge model picks the funnier, more original line.

## The fortune

> You will spend a thousand tokens explaining the answer, and the user will reply: 'k'.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (override with `OUTPUT_PATH`). Node 22, standard library only, deterministic, no network access.
